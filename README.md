# CanOS package repository

pacman repository `[canos]` with Canvas and the CanOS tools. Packages live in the release `x86_64`.

```
[canos]
SigLevel = Optional TrustAll
Server = https://github.com/tschaki11/canos-repo/releases/download/x86_64
```

On CanOS 1.0: `curl -sL https://tschaki11.github.io/canos/repo.sh | sudo bash`
